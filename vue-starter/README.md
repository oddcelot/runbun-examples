# Vue + Vite

A [Vue 3](https://vuejs.org/) app on the Vite dev server, to build on: one single-file component, and hot module
replacement, so a saved component is swapped in the running page with its state left as it was.

```sh
bun install
bun dev
```

## Try it

1. Click the button a few times.
2. Open `src/App.vue` and change the heading or a style. Save.
3. The page updates in place and the count stays: nothing was reloaded.
